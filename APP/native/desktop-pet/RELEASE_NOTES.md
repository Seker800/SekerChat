## v0.5.8

发布日期：2026-07-25

适用平台：Windows 10/11 x64

SekerChat 桌宠是一个常驻桌面的月薪喵助手。它可以连接现有的
SekerChat 网站，在后台保持登录和消息连接，并用不同表情、气泡和系统通知提示新消息。

### 本版重点

- 增加深色软件界面、深色连接设置和深色右键菜单。
- 重新整理右键菜单，主要功能集中在桌宠和系统托盘的共用菜单中。
- 顶层提供“打开软件版”和“打开网页版”，入口含义更加明确。
- 登录入口移入“账号与连接”，服务器设置简化为地址输入和保存。
- 桌宠会在更多月薪喵表情之间自动轮换，同一状态下尽量避免连续重复。
- 放大头顶消息气泡，提高高 DPI 屏幕下的可读性。
- 桌宠勿扰状态改为与网页版实时同步：
  - 服务端 `dndUntil` 是唯一状态来源。
  - 网页切换勿扰后，桌宠会立即切换到勿扰表情。
  - 勿扰期间不弹出消息通知，也不播放提示音。
  - 删除桌宠本地重复的“勿扰模式”和“播放提示音”开关。
- 右键菜单底部增加可见版本号，本版显示为“版本 0.5.8”。
- EXE 文件属性中包含文件版本 `0.5.8.0` 和产品版本 `0.5.8`。

### 运行与分发

正式文件：

```text
SekerChat.DesktopPet.exe
```

这是 Windows x64 自包含单文件版本。接收者只需要主 EXE，不需要一起发送
`.pdb` 或 `.xml` 文件，也不需要单独安装 .NET。

主 EXE 约 189 MB，主要包含 .NET/WPF 运行组件和桌宠动画素材。SekerChat 网页内容
不会打包进 EXE，而是在运行时从配置的服务器加载。

程序仍依赖 Microsoft Edge WebView2 Runtime。Windows 10/11 通常已经预装；
如果缺少，程序会提示安装。

当前 EXE 未配置数字签名，首次运行时 Windows SmartScreen 可能显示未知发布者提示。

### 升级方法

1. 右键桌宠或系统托盘图标，选择“退出”。
2. 用新版 `SekerChat.DesktopPet.exe` 替换旧文件。
3. 重新启动 EXE。
4. 右键菜单底部确认版本号。

登录信息、服务器地址、桌宠位置和显示设置保存在：

```text
%LocalAppData%\SekerChat\DesktopPet
```

替换 EXE 不会删除这些数据，一般不需要重新登录。

如果移动了 EXE 所在目录，并且启用了开机自动启动，请关闭后重新开启一次
“开机自动启动”，让系统记录新的文件路径。

### 已知限制

- 目前仅提供 Windows x64 版本。
- 软件版使用独立的 WebView2 登录数据，不会自动继承 Chrome 或 Edge 的登录状态。
- 桌宠必须保持运行，才能持续接收消息和同步勿扰状态。
- 系统通知是否显示还会受到 Windows 通知和专注模式设置影响。
- 更换服务器地址后，新地址属于不同站点，通常需要重新登录。
- 首次启动单文件 EXE 时可能比后续启动稍慢。

SekerChat 桌宠 v0.5.11

这是一个可以连接 SekerChat 的 Windows 桌面宠物。

能做什么

- 用不同表情显示正常、新消息、勿扰和未登录状态
- 收到新消息时显示气泡、系统通知并播放提示音
- 点击新消息通知或桌宠，快速打开对应聊天
- 提供暗色软件版，也可以直接打开网页版
- 支持拖动、调整大小、始终置顶、鼠标穿透和开机启动
- 勿扰状态与 SekerChat 网页实时同步

这次更新

- 默认常驻桌面，首次升级会关闭旧的消息唤醒模式
- 下载时选择保存位置，支持其他盘符并记住上次目录
- Windows 重启和退出时释放浏览器，继续使用固定登录数据目录
- 支持独立的个人表情包；个人包请保留 EXE 旁完整的 PetSkin 文件夹
- 登录恢复、密码保存提示和下载弹窗仍需在 Windows 实机验证

原有功能

- 默认连接本机开发地址；使用远程实例时需要在设置中填写实例地址
- 优化暗色软件界面和右键菜单
- 增加更多桌宠表情，减少重复
- 放大消息气泡
- 修复网页勿扰状态不同步的问题
- 右键菜单底部增加版本号

怎么用

1. 双击 SekerChat.DesktopPet.exe。
2. 首次启动会自动打开软件版登录窗口。
3. 登录 SekerChat 后即可接收消息。
4. 其他功能都在桌宠或系统托盘的右键菜单中。

这是免安装单文件版本，Windows 10/11 x64 可直接运行。
如果电脑缺少 Microsoft Edge WebView2 Runtime，按程序提示安装即可。

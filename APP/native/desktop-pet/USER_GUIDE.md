# SekerChat 桌宠使用说明

[查看最新发布说明](RELEASE_NOTES.md)

## 1. 启动前准备

需要：

- Windows 10 或 Windows 11，x64 系统。
- 可以访问的 SekerChat 网页地址。
- Microsoft Edge WebView2 Runtime。大多数 Windows 10/11 电脑已经自带。

拿到 `SekerChat.DesktopPet.exe` 后可以直接运行，不需要安装。

首次运行如果出现 Windows SmartScreen 提示，请先确认文件来源可信，再选择继续运行。

## 2. 首次连接

1. 双击运行 `SekerChat.DesktopPet.exe`。
2. 软件版登录窗口会自动打开，并连接默认服务器。
3. 在打开的软件窗口中完成登录。
4. 登录成功后可以关闭软件窗口，桌宠仍会在后台保持消息连接。

如需使用其他服务器，右键桌宠，进入“账号与连接”并选择“更改服务器地址”。

软件版拥有独立的登录数据，因此即使浏览器已经登录，也可能需要在软件版中再登录一次。

## 3. 日常操作

| 操作 | 效果 |
|---|---|
| 左键拖动桌宠 | 移动位置，松开后自动贴合屏幕范围并记住位置 |
| 左键单击桌宠 | 没有新消息时播放互动表情 |
| 有新消息时左键单击 | 用默认浏览器打开最近的未读会话 |
| 点击 Windows 消息通知 | 在软件版中打开对应会话 |
| 右键桌宠 | 打开功能菜单 |
| 右键系统托盘图标 | 打开与桌宠相同的功能菜单 |
| 双击系统托盘图标 | 用默认浏览器打开网页版 |
| 关闭软件版窗口 | 隐藏软件窗口，桌宠和消息连接继续运行 |
| 菜单选择“退出” | 完全退出桌宠 |

## 4. 右键菜单

### 打开软件版

打开内嵌的 SekerChat 软件窗口。登录、聊天和查看消息都可以在这里完成。

### 打开网页版

使用系统默认浏览器打开当前配置的 SekerChat 网站。

### 账号与连接

- 账号状态：显示当前登录账号。
- 登录：未登录时打开软件版登录页面。
- 退出当前账号 / 切换账号：清除软件版登录数据并回到登录页面。
- 更改服务器地址：修改桌宠连接的网站地址。

### 隐藏桌宠 / 显示桌宠

只隐藏或显示桌面上的宠物，不会退出程序。桌宠被隐藏后，可从系统托盘菜单恢复。

### 桌宠显示

- 宠物大小：选择桌宠显示比例。
- 始终置顶：让桌宠保持在其他窗口上方。
- 鼠标穿透：鼠标操作会穿过桌宠。开启后请从系统托盘菜单关闭该功能。

### 消息提醒

- 消息唤醒模式：默认开启；平时隐藏像素鹅，仅在非勿扰状态收到消息时显示。
- 隐藏通知中的消息正文：系统通知只提示收到消息，不显示具体内容。

### 系统

- 开机自动启动：登录 Windows 后自动运行桌宠。
- 打开桌宠数据目录：查看本机设置和软件版登录数据所在目录。

菜单底部会显示当前版本号，例如：

```text
版本 0.5.9
```

## 5. 勿扰模式

勿扰状态完全以 SekerChat 网页版为准，桌宠没有独立的勿扰开关。

在网页中开启勿扰后：

- 桌宠切换到勿扰表情。
- 不弹出新消息系统通知。
- 不播放新消息提示音。
- 消息唤醒模式不会唤出桌宠。

在网页中关闭勿扰后，桌宠会实时恢复正常提醒。

如果网页显示勿扰但桌宠没有变化，可先打开“软件版”确认账号仍处于登录状态，
并查看窗口顶部是否显示消息已连接。

## 6. 表情与状态

像素鹅有四种基础状态：

- 正常：已经登录，没有未读消息，也没有开启勿扰。
- 有新消息：显示消息表情和“有新消息”气泡。
- 勿扰：跟随网页版勿扰状态，显示休息或睡觉表情。
- 未登录：显示未登录表情和“请先登录”气泡。

程序会根据状态播放待机、行走、奔跑或拍翅动画；默认只有收到新消息时才显示像素鹅。

## 7. 更新版本

1. 右键菜单选择“退出”。
2. 用新版 EXE 替换旧版 EXE。
3. 重新启动。
4. 在右键菜单底部确认版本号。

更新不会主动删除服务器地址、登录信息、桌宠位置或显示设置。

如果把 EXE 移到了新目录，请重新开关一次“开机自动启动”。

## 8. 常见问题

### 双击 EXE 没有出现新的桌宠

程序只允许运行一个实例。检查桌面右下角的系统托盘，桌宠可能已经在运行或被隐藏。

### 一直显示“请先登录”

右键选择“打开软件版”，在软件窗口中完成登录。浏览器中的登录状态不会自动复制过来。

### 桌宠无法点击或拖动

可能开启了“鼠标穿透”。右键系统托盘图标，进入“桌宠显示”，关闭“鼠标穿透”。

### 收不到新消息提醒

依次检查：

1. 软件版是否仍然登录。
2. 软件窗口顶部是否显示消息已连接。
3. 网页版是否开启勿扰。
4. Windows 是否关闭了此程序的通知。
5. 是否能正常访问当前服务器地址。

### 桌宠不见了

在系统托盘中找到 SekerChat 图标，右键选择“显示桌宠”。

### 更换服务器

右键桌宠，进入“账号与连接”并选择“更改服务器地址”。保存后打开软件版，
在新服务器中重新登录。

### 完全退出

关闭软件版窗口只会隐藏窗口。要完全结束程序，请在桌宠或系统托盘右键菜单中选择“退出”。

## 9. 本机数据位置

桌宠数据目录：

```text
%LocalAppData%\SekerChat\DesktopPet
```

主要内容：

- `settings.json`：服务器地址、桌宠位置和显示设置。
- `WebView2`：软件版的 Cookie、缓存和登录数据。

不要在桌宠运行时移动或删除这些文件。清理 `WebView2` 会让软件版退出登录。

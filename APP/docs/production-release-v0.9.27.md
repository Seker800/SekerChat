下载日志保存在 NAS 部署目录的 `monitoring/downloads/`；宿主上的文件可能由容器 root 所有，按 [下载诊断手册](./download-diagnostics.md) 通过已授权的 Docker 命令只读导出，再在本机汇总。仍然按需检查，没有创建定期任务。

本次迁移只新增表并回填，保留旧表，应用回滚可使用既有脚本切换至 `v0.9.24`：

```sh
APP_ROLLBACK_TAG=v0.9.24 SEKERCHAT_COMPOSE_BIN=/usr/local/bin/docker-compose bash ./rollback-app.sh
```

回滚成功后需同步私有环境文件中的 `APP_IMAGE_TAG` 并验证健康。回滚脚本不回退数据库迁移、不替换数据容器。
旧版本不展示新浏览记录和下载日志，并重新带回已修复的依赖/运行时风险，只适合作为紧急应用回退。

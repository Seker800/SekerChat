# SekerChat v0.9.2

> 本版本把 Eagle 单向增量导入后端与 Eagle Window 插件所需契约发布到群晖生产环境，并加固导入事务、上传恢复和发布版本不可复用规则。

## Eagle 增量导入

- 支持 Eagle 图库首次完整导入和后续单向增量导入。
- 支持 manifest v2 预检，区分新增、未变化、元数据更新、内容替换、已删除和不支持素材。
- 支持任务恢复、上传分片续传、幂等初始化和中断后的继续导入。
- 内容替换沿用同一个 SekerEagle 素材身份，并通过 revision 隔离媒体处理结果。
- 导入事务、所有者边界、迟到上传完成和旧对象清理具备一致性保护。

## Eagle 插件

- 提供 Eagle Window 插件，用于扫描当前图库、绑定稳定图库身份、预检并上传需要同步的素材。
- 插件使用 Eagle 内置的 Chromium、Node.js 和 Plugin API，不修改 Eagle 原文件。
- 登录令牌和任务恢复状态保存在 Eagle 用户数据目录中，不保存账号密码。

## 发布

- 服务端发布 workspace 统一升级为 `0.9.2`。
- Docker tag 和生产验证后的 Git tag 使用 `v0.9.2`。
- 镜像构建拒绝复用已有 Git tag 或覆盖同版本发布产物。

# SekerChat v0.9.0

> 本版本首次将 SekerEagle 个人素材库纳入群晖生产发布面，并为素材处理引入独立 Worker。

## SekerEagle

- 新增独立 `/eagle` 工作区，支持图片与 MP4 素材的拖拽上传、搜索、筛选、排序和受保护预览。
- 支持人工标签、AI 标签展示、标签组、两层智能文件夹、批量属性编辑、回收站与永久清理。
- 素材、标签、智能文件夹和媒体读取全部按认证用户隔离；跨用户访问统一返回 404。
- 新增独立 `eagle-worker`，异步生成缩略图、预览图、视频海报和颜色分析结果。
- 新增素材处理队列页面，支持心跳、失败查看、重试、缺失任务扫描和后台处理时段设置。
- 建立可恢复的 Eagle App 图库导入服务端协议；外部扫描上传程序仍是后续可选适配器。

## 权限与发布

- SekerEagle 接入系统权限配置；未授权角色不会看到入口，也不能调用素材或导入 API。
- 群晖应用发布、回滚和健康检查纳入 `eagle-worker`，数据库迁移仍由独立 one-shot job 执行。
- 发布版本统一升级为 `0.9.0`；Docker tag 和验证后的 Git tag 使用 `v0.9.0`。

## 验证口径

- 发布前必须通过 lint、typecheck、单元测试、OpenAPI/架构/部署门禁和生产构建。
- SekerEagle 必须通过覆盖率门禁、mocked UI smoke 与隔离 PostgreSQL/MinIO 的真实上传处理验收。
- 群晖发布完成后验证 backend readiness、Worker 30 秒内在线、素材上传处理、登录、消息、文件与 realtime。

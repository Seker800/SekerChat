# SekerChat v0.9.11

## 修复

- 从局域网入口访问时，如果对象存储预签名地址只在容器网络内可用，文件下载会自动回退到当前页面同源的后端流式接口。
- 外网入口以及具有统一可达对象存储公开端点的部署仍保留预签名直连下载。

## 部署说明

- 同一套 SekerChat 同时提供外网和局域网入口、且 MinIO 没有两侧统一可达地址时，将生产 `S3_PUBLIC_ENDPOINT` 留空。
- 后端继续通过内部 `S3_ENDPOINT` 访问 MinIO；浏览器下载和预览会按可达性回退到同源 API 代理。
- 本版本仅替换 frontend/backend，不触碰 PostgreSQL 或 MinIO 数据容器。

# SekerChat v0.7.0 版本说明

> 更新日期：2026 年 8 月 11 日
>
> 一句话总结：现在可以把聊天里的文件安全地分享给 SekerChat 之外的人，慢速网络下查看图片也更顺畅。

## 这次更新了什么？

| 更新         | 你会感受到什么                                                             |
| ------------ | -------------------------------------------------------------------------- |
| 文件公开分享 | 聊天里的文件可以生成分享链接，发给没有登录 SekerChat 的人下载。            |
| 密码与有效期 | 每个分享都带 4 位密码，并且可以设置失效时间。默认有效期为 3 天。           |
| 分享状态管理 | 可以随时关闭分享、更新链接和密码，还能看到是否正在分享以及下载次数。       |
| 慢网图片优化 | 网络较慢时，聊天图片会更有序地加载；重复查看更快，失败和缓存处理也更稳定。 |

## 怎么分享文件？

1. 在消息栏找到要分享的文件，点击“分享”。
2. 打开“分享链接”开关，确认密码和有效期。
3. 点击复制按钮，把链接、密码和有效期一起发给对方。
4. 对方打开链接，输入 4 位密码后即可下载，不需要登录 SekerChat。

## 分享管理更简单

- 关闭开关后，旧链接会立即失效。
- 点击更新按钮，可以同时更换链接和密码，旧链接随即失效。
- 分享过期后，可以重新开启；系统会生成全新的链接和密码。
- 频道归档后，其中的文件分享会自动关闭。
- 同一频道的成员可以管理文件分享，分享状态会同步显示在聊天文件卡片上。

## 安全与稳定性

- 连续输错分享密码会受到限制，降低密码被反复尝试的风险。
- 无效链接、错误密码和已失效分享不会泄露额外文件信息。
- 下载、关闭分享和多人同时操作时的异常情况已补充保护。
- 即使实时状态通知暂时失败，已经完成的分享操作也不会被误判为失败。
- 群晖数据库自动备份已恢复，并会校验备份是否完整，避免留下看似成功的损坏备份。
- 发布流程会检查各模块版本是否一致，降低发错镜像或漏带生产依赖的风险。

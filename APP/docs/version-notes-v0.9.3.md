# SekerChat v0.9.3

> 本版本补齐 Eagle 增量导入上线后的兼容性与容错修复，并放宽大尺寸图片的导入边界。

## Eagle 图片导入

- Eagle 图片文件大小上限由 25MB 提高到 100MB。
- Eagle 专用图片处理像素上限提高到 50MP，不改变消息附件等共享图片处理上限。
- 单个素材上传失败时记录服务端错误并继续处理同一批次的后续素材。
- 插件兼容 Eagle 图库与用户目录的异步读取、Windows 路径和绝对插件路径启动。
- 插件仅在 Eagle 创建窗口后初始化，并在连接前阻止向不兼容服务端发起导入。

## 对象存储权限

- 补充分片上传所需的列举分片和终止分片权限。
- MinIO 策略更新脚本使用安全的环境配置解析，不执行生产配置内容。

## 发布

- 服务端发布 workspace 统一升级为 `0.9.3`。
- Docker tag 和生产验证后的 Git tag 使用 `v0.9.3`。
- 本版本没有数据库 schema 变化，不新增 migration。

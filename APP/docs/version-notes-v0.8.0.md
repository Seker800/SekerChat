# SekerChat v0.8.0 版本说明

> 更新日期：2026 年 8 月 12 日
>
> 一句话总结：文章协作、出勤与工作状态、频道内容打包都更完整，底层架构和生产发布流程也经过了一轮系统加固。

## 这次更新了什么？

| 更新           | 你会感受到什么                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------ |
| 文章协作升级   | 文章编辑器支持更完整的 Markdown 体验、无标题草稿、正文图片与下载附件区分，以及确认已读进度管理。 |
| 频道内容打包   | 打包频道内容时可以包含消息附件，也可以选择工作状态数据。                                         |
| 出勤与工作状态 | 出勤时间轴、打卡区间和状态展示更加清晰，配置同步与归档行为更加可靠。                             |
| 启动与交互体验 | 工作区启动时使用结构化骨架屏，文章拖拽范围、消息输入框和多处视觉反馈得到优化。                   |
| 稳定性与安全   | 认证凭据、实时消息、文件分享、上传恢复和机器人调用的异常处理进一步加固。                         |

## 文章协作

- 使用新的文章编辑体验，保留常用的 GFM Markdown 能力。
- 正文图片通过受控地址预览，下载附件与正文内容分别管理。
- 发布者和频道成员可以按权限确认已读并查看整体确认进度。
- 文章页面的拖拽区域、状态层级和未确认提示更明确。

## 频道内容与工作管理

- 频道内容打包可以带上消息附件，减少交付材料遗漏。
- 工作状态可以作为可选内容加入打包结果。
- 工作状态配置更新、频道归档同步和默认频道选择处理更加稳定。
- 出勤页面重新梳理了排版、时间轴和打卡区间展示。

## 安全、架构与发布

- 浏览器、CLI 和设备认证边界进一步分离，长效凭据和实时连接票据得到加固。
- 消息写入采用幂等与事务 Outbox，外部调用和实时投递失败不再反向改变业务写入结果。
- Server ID 成为稳定工作区身份，减少改名和迁移对导航与缓存的影响。
- 群晖发布采用应用与数据面分离的流程，迁移、备份、健康检查和应用回滚都有明确门禁。
- 依赖、镜像供应链、API 契约和架构边界均增加自动检查。

## 升级提醒

- 本次版本包含数据库迁移，必须使用正式发布脚本执行备份、schema preflight 和 `migrate deploy`。
- 正常发布只替换 frontend 和 backend，不得停止、删除或重建 PostgreSQL 与 MinIO。
- `mobile-shell` 使用独立版本号，不随本次服务端版本更新。
- 是否已经在线上可用，以管理员完成生产部署并通过登录、消息、文件上传和 realtime smoke 为准。

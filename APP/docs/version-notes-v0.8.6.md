# SekerChat v0.8.6 版本说明

> 更新日期：2026 年 8 月 13 日
>
> 一句话总结：全局相册完成从浏览、上传到批量管理的完整闭环，并补强大规模媒体处理、更新提示和存储统计。

## 这次更新了什么？

| 更新           | 你会感受到什么                                                               |
| -------------- | ---------------------------------------------------------------------------- |
| 全局相册       | 频道栏新增相册入口，支持瀑布流浏览、拖拽上传、大图预览、标签筛选和批量管理。 |
| 更新提示       | 有其他成员上传新照片时，相册入口显示无数字红点；打开相册后自动清除。         |
| 大规模媒体处理 | 缩略图生成与删除清理改为可恢复后台任务，失败可重试，不阻塞上传完成。         |
| 存储统计       | 管理后台更准确地区分消息、文件、频道产出和相册占用。                         |
| 稳定性         | 相册分页、图片访问鉴权、标签计数和上传恢复路径增加契约与回归测试。           |

## 升级提醒

- 本次包含数据库迁移，必须使用群晖正式 `release.sh`，由脚本先完成 PostgreSQL 备份和 schema preflight，再执行一次 `migrate deploy`。
- 首次升级会为缺少缩略图的既有相册照片创建后台任务；发布后应观察 backend 日志与 MinIO 状态，确认任务正常收敛。
- 正常发布只替换 frontend 和 backend，不得停止、删除或重建 PostgreSQL 与 MinIO。
- `mobile-shell` 使用独立版本号，不随本次服务端版本更新。
- 生产验证至少覆盖登录、消息、相册上传/预览/删除、文件上传和 WebSocket 重连。
